LIVE GPS TRACKING & JOURNEY

ระบบติดตามและนำทางแบบเรียลไทม์ (Sub-Second Live Sync)

จำลองการเดินทางของเจ้าหน้าที่ลงพื้นที่ พร้อมเปรียบเทียบการอัปเดตแบบสดบนหน้าเว็บ

STEP 01 รับงาน & ออกตรวจ
เปิดสิทธิ์ GPS แม่นยำสูง (HighAccuracy) + WakeLock

เจ้าหน้าที่กดเริ่มเดินทาง ระบบขอสิทธิ์พิกัดดาวเทียม และเปิด Screen WakeLock ป้องกันหน้าจอดับ

STEP 02 ระหว่างเดินทาง (Optimize แล้ว)
Movement-Aware ส่งทันทีเมื่อขยับ · ซิงก์ใน 0.48 วิ

ส่งพิกัดขึ้นเซิร์ฟเวอร์ทันทีที่เคลื่อนที่ ≥1.5 ม. ประชาชนเห็นหมุดขยับอย่างลื่นไหล ไม่กระตุก

STEP 03 ถึงหน้างาน
เข้าสู่จุดเกิดเหตุ & สิ้นสุดการแชร์พิกัด

เมื่อระยะห่างถึงเป้าหมาย ระบบแจ้งเตือนประชาชน และปิดการแชร์พิกัดอัตโนมัติเพื่อความเป็นส่วนตัว

สารบัญสไลด์ Final Pitching

    รายละเอียดผลทดสอบ Real-Time GPS (Automated Benchmark)

    สภาพแวดล้อมการทดสอบ: Playwright Dual-Browser Automation บน Chromium (จำลอง Browser เจ้าหน้าที่และผู้แจ้งพร้อมกันบน Localhost และฐานข้อมูล SQLite แยก)

    จุดพิกัด พิกัด (lat, lng) ดีเลย์ก่อนแก้ (Before) ดีเลย์หลังแก้ (After) ความเร็วที่เพิ่มขึ้น ความแม่นยำระยะทาง
    WP1 13.1120, 99.9420 7,825 ms (429: 10 ครั้ง) 792 ms (429: 0 ครั้ง) เร็วขึ้น 9.9 เท่า 99.998%
    WP2 13.1140, 99.9440 10,014 ms (429: 10 ครั้ง) 620 ms (429: 0 ครั้ง) เร็วขึ้น 16.2 เท่า 99.997%
    WP3 13.1160, 99.9460 9,923 ms (429: 10 ครั้ง) 342 ms (429: 0 ครั้ง) เร็วขึ้น 29.0 เท่า 99.997%
    WP4 13.1180, 99.9480 10,105 ms (429: 9 ครั้ง) 146 ms (429: 0 ครั้ง) เร็วขึ้น 69.2 เท่า 99.997%

    สรุปผลการปรับปรุง: ดีเลย์เฉลี่ยลดลงจาก 9,467 ms (9.47 วินาที) เหลือเพียง 475 ms (0.48 วินาที) หรือเร็วขึ้นกว่าเดิม 19.9 เท่า (ลดดีเลย์ 95.0%) และขจัดปัญหา HTTP 429 ได้ 100%

    แหล่งข้อมูลและวิธีการวัดผล

    1. แบบสำรวจความต้องการผู้ใช้

    กลุ่มตัวอย่าง 38 รายในพื้นที่อำเภอเมืองเพชรบุรี (23 อาศัยในเขตเทศบาล, 15 สัญจรประจำ) พบ 94.4% มีปัญหาในการติดตามเรื่อง และ 78.9% ต้องการระบบแจ้งเตือนอัตโนมัติ

    2. สถาปัตยกรรมและโค้ดระบบจริง

    พัฒนาด้วย Django 5.2, Python, MapLibre GL, Web Push และ SQLite/MySQL ตามโครงสร้างใน codebase phetpri_project

    3. การทดสอบ Real-Time GPS Tracking

    วัดผลแบบ End-to-End ด้วย Playwright Chromium จำลองการเคลื่อนที่จริงและวัดเวลาที่หมุดแผนที่ของผู้แจ้งอัปเดตแบบมิลลิวินาที

    สแกนเปิดใช้งาน PhetpriReport
